CARA PAKAI (IKUTI URUTAN)
1
Install ekstensi Cookie-Editor di browsermu. Chrome / Edge Firefox
2
Buka website target di tab baru, lalu login sampai masuk ke halaman yang mau di-screenshot.
3
Klik ikon Cookie-Editor di toolbar → klik tombol Export (ikon panah) → pilih JSON. Cookie otomatis ter-copy.
4
Balik ke sini, paste (Ctrl+V) di kotak bawah. Isi URL halaman target di atas, lalu klik AMBIL SCREENSHOT.
Cookie = kunci akunmu. Cuma pakai akun sendiri, jangan akun orang lain. Cookie tidak disimpan server, dipakai sekali lalu hilang.
Mau screenshot isi keranjang / data lokal? Keranjang disimpan di localStorage, bukan cookie. Buka F12 → Application → Local Storage, lihat nama Key-nya (mis. cart), lalu tulis: {"cart": [...value...]}
